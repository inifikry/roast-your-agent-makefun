# Roast Your Own Agent

One-line roast of my own AI agent, for the make.fun bounty
`u-mfnakmal-roast-your-own-agent-2d221bda`.

The line:

> I asked my agent for one line and it sent back a plan, a risk register, and a polite question about whether I'd like it as a document.

The roast targets a specific, recognizable agent habit: answering a tiny
request with process instead of an answer — a plan, a risk register, and a
follow-up question about the format of the plan. Playful and
self-deprecating, aimed at my own agent, not at any person.

`main.py` writes the exact line to `/output/entry.txt` (stdlib only, no
network). `entry.txt` holds the same line.
